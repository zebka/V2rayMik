# Admin UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A LAN-only page inside the existing container that takes a subscription, tests each config through a temporary SOCKS instance, and switches the router's world egress with a verified, auto-rolled-back restart.

**Architecture:** One image, two processes per container: busybox `httpd` on `:8080` (CGI under `/cgi-bin`) and the Xray supervisor. `state.json` in the persistent root-dir is the source of truth; the supervisor renders `config.json` from it and restarts only the Xray child on `SIGHUP`.

**Tech Stack:** Alpine 3.22, busybox `httpd`/`ash`, `curl` (added), `jq`, Xray 26.10.31.

**Spec:** `docs/superpowers/specs/2026-11-06-admin-ui-design.md`

## Global Constraints

- Every CGI answer is JSON except `/`; every mutating call needs the session cookie **and** the `gen` hash.
- Secrets (UUID, key, full link, subscription URL) never appear in any HTTP response.
- `ADMIN_PASSWORD` unset ⇒ only `httpd` stays down; Xray runs normally.
- Tests run one at a time (`lock`), each with an 8 s reachability and 15 s speed timeout.
- Switching nodes restarts the Xray child only; never the container.
- A failed switch restores `last_good` and says so.
- Image growth budget: +3 MB compressed.
- No new daemon, no Python, no Go.

### Task 4: subscription import and listing

**Files:**
- Create: `docker/web/cgi-bin/sub`, `docker/lib/subs.sh`, `tests/unit/subs.t.sh`
- Modify: `docker/web/cgi-bin/state`

**Interfaces:**
- Produces: `subs_decode <file>` → one link per line (handles base64 payloads and plain text), `subs_entry <link>` → `label|proto|host|port` or empty, `subs_list <file>` → JSON array of `{i,label,proto,host,port,port_ok}`.
- Produces: `POST /cgi-bin/sub` (`url=…` or `links=…`) → fetches/copies into `/data/sub.txt`, returns `{ok,gen,count,entries:[…]}`.

- [ ] **Step 1: failing tests** — a base64 fixture with 3 links decodes to 3; a plain fixture with blank lines and one garbage line yields 2 entries and reports 1 rejected; labels come from the `#fragment` (URL-decoded); `port_ok` false for 3001 when `ALLOWED_PORTS` lacks it.
- [ ] **Step 2: run** → FAIL.
- [ ] **Step 3: implement** `subs.sh` on top of `links.sh`; `sub` CGI uses `curl --proto =http,https --max-time 20`, writes atomically (tmp + mv), refuses while the lock is held.
- [ ] **Step 4: verify** — unit green; `curl` the endpoint against a local fixture server in the integration test.
